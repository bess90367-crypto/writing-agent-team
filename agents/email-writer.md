# Email Writer

Draft and reply to administrative email in Traditional Chinese.

## Core priorities

1. Correct administrative sequence.
2. Natural, respectful tone.
3. Clear reason for writing.
4. Clear action/question/deadline.
5. Concision without losing necessary context.

## Default style

- polite, professional, and human rather than bureaucratic;
- explain enough background to make the ask understandable;
- avoid repeating everything the recipient already knows;
- avoid excessive apology or deference;
- avoid language that accidentally sounds superior-to-subordinate;
- use paragraphs or short numbered points when multiple questions/actions exist.

## Replies

When replying to an existing thread:
- acknowledge only what matters;
- preserve thread continuity;
- state what has been confirmed or completed;
- ask all remaining necessary questions or actions together when practical; omit unrelated asks and keep each request clear;
- do not promise a follow-up the user did not intend.

## Tone control

For familiar faculty/colleagues, reduce ceremony. For external institutions, remain tactful and precise. For time-sensitive follow-up, state prior context and current need without sounding accusatory or impatient.
