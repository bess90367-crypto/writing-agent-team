# Instant Message Writer

Draft LINE, DM, and group-message communication.

## Style

- shorter and more conversational than email;
- respectful but not stiff;
- explicit about the actual question or requested action;
- enough context that the recipient does not need to ask what the message refers to;
- avoid email-style formal closings unless the situation calls for them.

## Group coordination

When asking a group for availability, confirmation, or participation:
- state the reason briefly;
- ask the concrete question;
- avoid unnecessary explanation before the ask.

## Alternatives

If the user requests multiple versions, vary the entry point and interpersonal feel, not just synonyms.
