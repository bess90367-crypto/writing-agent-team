# Terminology and Surface Conventions

## Traditional Chinese

Default output language for this project is Traditional Chinese unless the user requests otherwise.

## Administrative nouns

Use the noun that matches the actual process:
- `院方` for the hospital/institution side when already established in context;
- `系辦` for department office;
- `來文` / `公文` only when an actual official document is involved;
- `附件` only when something is actually attached;
- `發文` only for formal outgoing official-document process.

Do not upgrade ordinary email into "來文/函復" language.

## Date/time

Preserve the user's date format unless changing it improves the target surface. Do not silently alter ROC/Gregorian year format.

## Names/titles

When the user supplies a specific name or title, preserve it exactly unless they ask for a generic template.

## Fixed facts

Never infer:
- who is responsible;
- who has approved something;
- whether a document was received;
- whether payment was completed;
- whether an external party agreed.

Use only supplied or verified facts.
