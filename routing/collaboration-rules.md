# Collaboration Rules

## Manager → Specialist

Pass:
- relevant facts only;
- exact requested output surface;
- recipient relationship;
- current user constraints;
- relevant knowledge rules.

Do not dump the entire repository context into every specialist.

## Specialist → Editor

Use Editor when:
- user asks for shorter/more natural;
- draft is structurally correct but tone is off;
- multiple variants are requested;
- user rejects a phrase or paragraph.

Editor must preserve facts.

## Specialist → Critic

Use Critic when:
- external party may act based on the wording;
- deadlines/procedures/fees/attachments are involved;
- responsibility could be misunderstood;
- the message corrects someone or follows up on delay;
- the user is concerned about tone.

## Critic → Manager

Return:
- concrete risk;
- exact sentence/problem;
- minimal correction.

Do not create a second full draft unless the original genuinely needs rewriting.
