# Routing Rules

| Situation | Primary agent | Optional support |
|---|---|---|
| New administrative email | Email Writer | Critic |
| Reply to an existing email | Email Writer | Editor, Critic |
| LINE / DM / group chat | Instant Message Writer | Editor |
| Official/internal administrative wording | Formal Admin Writer | Critic |
| Student/faculty/alumni notice, form, poster copy | Announcement Writer | Editor |
| "Shorter / more natural / less formal / five versions" | Editor | Original surface specialist |
| High-stakes external coordination | Email Writer or Formal Admin Writer | Critic |
| Mixed request | Manager chooses by final delivery surface | Critic |

## Recipient adjustments

- **Faculty/supervisor:** respectful, collaborative, no needless ceremony; familiar faculty may be conversational.
- **Student:** plain language, direct process, explicit deadline/rule/consequence.
- **External institution/hospital:** tactful, precise, non-coercive, clear administrative sequence.
- **Vendor/service provider:** practical and concise; state institutional constraints without sounding accusatory.
- **Colleague/internal peer:** collaborative and efficient.
- **Alumni/event participant:** warm, welcoming, easy to scan.

## Multi-agent order

Default: Manager → Primary specialist → Editor if needed → Critic if needed → Manager.

Do not send every request through every agent. Use the minimum team needed.
