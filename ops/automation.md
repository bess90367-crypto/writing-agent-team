# Automated Maintenance

## Weekly self-review

A long-term scheduled task is configured to review the writing-agent repository and recent writing-project conversations.

Current cadence:
- weekly
- Monday morning
- timezone: Asia/Taipei

The review follows `ops/weekly-review.md`.

## Purpose

The schedule is a safety net, not a substitute for incremental updates. Reusable feedback should still be incorporated when it appears; the weekly review catches anything missed and audits for rule drift or conflict.
